Folder ini berisi kode program Arduino yang digunakan pada proyek Smart Blind Stick with VL53L1X ToF Sensor. Program ini mengatur komunikasi mikrokontroler dengan sensor VL53L1X serta sistem peringatan untuk mendeteksi objek atau halangan di sekitar pengguna.

File program utama akan ditambahkan setelah diperoleh dari anggota kelompok.
