# Smart Blind Stick with VL53L1X ToF Sensor

## Project Based Learning (PBL)

### 1. Deskripsi Proyek

Smart Blind Stick merupakan alat bantu yang dirancang untuk membantu penyandang tunanetra dalam mendeteksi objek atau halangan di sekitarnya. Proyek ini menggunakan sensor VL53L1X Time-of-Flight (ToF) untuk mengukur jarak antara tongkat dan objek.

### 2. Tujuan Proyek

- Membantu penyandang tunanetra mendeteksi halangan di sekitarnya.
- Mengimplementasikan sensor VL53L1X ToF pada alat bantu.
- Mengembangkan teknologi sederhana berbasis mikrokontroler.

### 3. Komponen Proyek

- Mikrokontroler
- Sensor VL53L1X ToF
- Komponen elektronik pendukung
